# 개구리 — 설치 파일

화면 오른쪽 아래에 사는 청개구리에게 물어보면 한두 줄로 딱 답해주는 맥 앱이에요.

- **받기:** 오른쪽 [Releases](../../releases/latest)에서 `GanmyeongFrog-…-arm64.dmg`를 받으세요. (애플 실리콘 맥용)
- **쓰려면 라이선스 키가 필요해요.** 키는 구매하신 분께 따로 보내 드려요. 키 없이는 열리지 않아요.

## 처음 열기 (한 번만 하면 돼요)

애플 정식 서명 전이라 처음에는 경고가 떠요. 앱에 문제가 있다는 뜻이 아니에요.

1. 받은 `.dmg`를 열고, 개구리 앱을 **응용 프로그램** 폴더로 끌어다 놓아요.
2. 응용 프로그램 폴더의 개구리 앱을 **더블클릭**해요. "열 수 없습니다" 같은 경고가 뜨면 **완료**(또는 확인)를 눌러요.
3. **시스템 설정 → 개인정보 보호 및 보안**으로 가요.
4. 아래쪽으로 내리면 "개구리(GanmyeongFrog)가 차단되었습니다"라는 안내와 **그래도 열기** 버튼이 있어요. 눌러요.
5. 비밀번호(또는 Touch ID)를 확인하면 열려요. 그다음부터는 평소처럼 열려요.

> 예전처럼 앱을 우클릭해서 "열기"를 눌러도 최신 macOS에서는 같은 경고만 떠요. 위의 순서로 해 주세요.
> "손상되었기 때문에 열 수 없습니다"라고 나오면 받은 파일이 깨진 거예요. 다시 받아 보시고, 계속 그러면 알려 주세요.

## 쓰는 법

- **질문하기:** 개구리를 누르거나 `⌘ + Shift + Space`
- **복사한 글로 질문하기:** 글을 복사(`⌘C`)한 뒤 `⌘ + Shift + K`
- **개구리 집:** 개구리를 우클릭(트랙패드는 두 손가락 클릭)
- 처음 "귀여운 개구리"를 고르면 내장 AI를 한 번 내려받아요. (작게 약 2.5GB / 크게 약 5GB, 이후에는 인터넷 없이도 돼요)

이 저장소에는 설치 파일만 올라와 있어요.
